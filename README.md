# Strand

A small menu bar inspector for your cables, chargers and network. Everything stays on your Mac.

## Install

macOS 14+ · Apple silicon

1. [Download Strand](https://github.com/lumen-xx/strand-releases/releases/latest), unzip and move **Strand.app** to **Applications**.
2. Open it. If macOS blocks it, go to **System Settings → Privacy & Security → Open Anyway**, or run:

```sh
xattr -dr com.apple.quarantine /Applications/Strand.app
```

Strand is not notarized yet. Only run this for Strand downloaded here.

## Use

- Click the connector icon in the menu bar to see what's plugged in, how fast it is and what powers your Mac.
- Switch to **Network** for traffic, listening ports and connections.

Updates: **Strand → Check for Updates…**

The source repository is private.
